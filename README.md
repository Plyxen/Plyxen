## 🧑‍💻 About me

- 🤖 I build **Discord bots** in Python: moderation, auto-mod, tickets, raid protection, clan applications
- ⚔️ Working on a **combat overlay & DPS meter for Aion 2**, written in C# / .NET with WPF
- 🍓 My bots run 24/7 on a **Raspberry Pi** as systemd services, backed by PostgreSQL
